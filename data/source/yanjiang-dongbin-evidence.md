## 前海路跨越点

用户截图的小地图显示前海路、月丰路及沿江高速的弧形匝道。与 OSM 和影像对位后，对应 [way/1212748044](https://www.openstreetmap.org/way/1212748044)（`building=roof; layer=2`，约 113.89838E、22.51037N）。旧包把它挤成 33.6 米估计建筑。影像显示沿着双向高架的浅色连顶和端部开口；[西部通道深圳侧接线工程建设纪实](https://news.sina.com.cn/s/2006-09-06/03419945523s.shtml) 在大南山北麓同位置记录隔声措施。综合判断为道路隔声罩，局部通风开口和侧壁材料未测。它与更北侧、交通运输局名单中的[前海主线收费站](https://jtys.sz.gov.cn/zwgk/ggqsydw/gsgl/)（`way/482234119`）不同。

隔声罩按源轮廓与三条已编译承载道路的重合里程定位：`way/1205104173` 的两段东行边，以及西行 `way/1205104171`、`way/1207759065`。顶盖、梁、柱与侧板分开碰撞；柱落在边缘护栏带内。罩下梁底净空 5.5 米、板厚 0.24 米、侧板厚 0.16 米、6 米梁间距均为程序化估计。前海路另有源隧道 `way/539377090`、`way/613720086`；不和上层高速相连，本次没有开通下层这两条源边。月亮湾侧其他匝道未纳入。

## 东滨隧道方向

[深圳交警通告](https://szjj.sz.gov.cn/szsgajjtjcjwzgkml/szsgajjtjcjwzgkml/qt/tzgg/content/post_6858485.html)区分东行往科苑南路和接驳区、沙河西路以及口岸货运车道，并明确沙河西路南行可进入西行隧道。[口岸交通组织通告](https://szjj.sz.gov.cn/m/YD_ZWGK/YD_TZGG/YD_GGJG/content/post_11895705.html)对应金湾东二路经金湾东四路进入西行隧道的地面接法；节假日交通措施不当成常态规则。

- 东行：S3 广深沿江高速 → 月亮湾立交主线 → 西部通道侧接线高架 `way/1205104170` → 西端进洞 `node/1839137039` → `way/101316381` → 源数据的短敞开段 `way/245048426` → `way/245048427`、`way/277041483` → `node/1839131177` 出洞 → `way/173087900` 接 `node/4729092578`。继续经内环路 `way/987961855`、`way/1354572312`、科苑南路 `way/311110724` / `way/737700513`、`way/479872462` 接地面东滨路 `way/737700511`。
- 西行：沙河西路南行 `node/5612922511` → `way/587615717`、`way/765935267`、`way/765935266`，在 `node/1928750275` 与口岸侧入口 `way/182515657` 合流 → `way/182515727`、`way/277041480`、`way/245048422`、`way/245048424` → `node/1839137079` 出洞接 `way/1205104169`，再并入 S3 西北方向。东行出洞路线不是西行入口，地图没有两向互转。
- 其余分支中，`way/574520328` 为东行往沙河西路的分流起点，口岸货运及出入境线为独立交通组织；本次未开通这些分支。此线路也不是桂庙隧道、滨海隧道或妈湾跨海通道。

两向纵断面、错层深差、顶板和挡墙尺寸为场景工程估计。洞顶至道路面名义 4.5 米，扣灯具后 4.38 米；这是模型净空，不是通行限高。源宽缺失处按来源车道数和可用范围估计，缺车道标注的短口按影像/分支用途估计。部分双洞中心线投影重叠，编译器校验实体竖向净距并保留独立身份。道路限速只用可解析的源规则及场景缺省值；未模拟实时封闭、口岸车道级限制或实测照度。东、西行样段最大估计纵坡分别为 4.92% 和 4.08%；口岸侧接入匝道局部为 6.74%，提前到同高后才进入两条入口的共同车行空间。
