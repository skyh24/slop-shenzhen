# 福田星河 COCO Park 一期东南门外接入

核对于 2026-11-12。项目地块是福华路南侧、福华三路北侧 `way/546582690`。入口对应一期东南角圆筒 `way/238825588` 及其建筑部件 `way/539435437`。福华路北侧 `way/529086160` 是购物公园地面街块。连城新天地的 B 至 C 口公共接续在地下，场所关系和来源见 [购物公园审计](shopping-park-audit.json)。

| 字段 | 核实范围与来源 |
| --- | --- |
| 身份和层级 | 福田区 2025 年活动场所名录分别列出一期一层东南门户外广场和门内中庭，还另列负一楼下沉广场。Aedas 的 2021 年竣工项目资料把东南圆筒与一期对应。 [福田区名录](https://www.szft.gov.cn/ftqwtj/gkmlpt/content/12/12556/post_12556616.html) · [Aedas 项目页](https://www.aedas.com/sc/project/futian-coco-park/) |
| 公开步行接入 | Aedas 供稿的改造后照片显示福华三路北侧和中心二路西侧人行空间通到东南门户外广场，公众在广场及玻璃门前活动。L1 动线图给出由室外向西北进圆筒的联系。证据支持门外到达，广场产权、现行开放时段和临时管制未知。 [设计图和竣工实景](https://www.archiposition.com/items/20240426050842) |
| 门槛和接地 | 竣工照片所见的门前接续无明显连续踏步。图照无垂直控制点和可核门槛尺度，门心、门宽、门槛厘米级高差及无障碍合规均待测。场景停点取前场，8 米为现有 `urban-datum` 派生标高。 [竣工实景](https://www.archiposition.com/items/20240426050842) |

场景走线以米制 `x` 东、`z` 南表示。起点 `(-498.3, 1201.7)` 在福华三路北侧人行空间，沿同一侧地面向北到 `(-498.3, 1177.2)` 的东南门前场，然后原路返回。两点是源图照结合锁定 OSM 轮廓和现有场景的模拟定位，终点精度不足以表示门线。场景路线避开两处尚缺实物识别的补充建筑足迹 `overture/08186836-5bbf-468b-bdff-c3198a55c23a` 与 `overture/a97df276-0832-4e3e-b1b4-8d594c6a821a`。入口门线、室内、过街、地下与规划连廊均未纳入路线。
