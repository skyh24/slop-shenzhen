# 06 街景与夜景

## 行道树

下表为初期树种模型候选及待核实的场景方向，不作为已确认的逐路段种植清单；不能只按道路等级确定树种：

| 树种 | 位置 | 形态 |
| --- | --- | --- |
| 大叶榕、细叶榕 | 老城区主路、深南大道 | 宽冠、深绿 |
| 凤凰木 | 次干道 | 伞形冠，夏季红花 |
| 木棉 | 深南大道中央绿化带 | 高直主干，春季红花 |
| 大王椰、狐尾椰 | 滨海大道、深圳湾公园、后海 | 细高单干、顶部羽叶 |
| 宫粉紫荆 | 支路 | 小冠、粉色 |

点位优先使用核实的 OSM `natural=tree` 或市政/景观资料。取消无条件每9米补种、路口统一留12米的规则；有来源的树列/植被面可作带标注的程序化布置，不能冒充单株实测。点位、树高、冠幅、树种和树龄分别记录来源，先检查道路、建筑、入口、树池及通行净空冲突。

### 新旧公园与大小树（2026-11-09 用户补充）

公园建成年代、改造状态和植被成熟度分别表达。成熟公园包含大小树和林下/开敞空间；新公园可能保留大树，旧公园也可能补植小树，不用建成年代机械决定树高。根据点位、影像和景观资料组织树冠、树列、草坪、步道与铺装；缺证据时标注外观估计，不推造准确树龄。住宅小区绿化同样按组团和年代/改造证据组织。完整规划见[12号文档第5节](12-URBAN-FABRIC-PLAN.md#5-公园行道树与植被成熟度)。

## 街道设施

- 路灯：双臂高杆灯（主路）、单臂灯（支路），暖白色
- 信号灯：L 形悬臂，倒计时屏
- 地铁出入口：OSM `railway=subway_entrance`，深圳地铁的银灰顶棚加线路色标识，写站名和口号；线路、车站、过滤规则（必须按 `network=深圳地铁`）见 [11-MVP.md](11-MVP.md) 第 3.4 节
- 人行天桥：深南大道、滨海大道上 OSM 标为 `footway + bridge` 的段
- 公交站：玻璃候车亭加站牌
- 共享单车停放区：美团黄、哈啰蓝、青桔绿三色单车成排

## 海湾与红树林

- 深圳湾公园沿岸种红树林（矮、密、深绿，根部在水面）
- 退潮滩涂：海岸外 30 到 120 米用浅褐色半透明面
- 远处海面可见深圳湾大桥（远景外观：S 形桥面、桥墩、斜拉塔和拉索，夜里路灯带），西侧远处是广深沿江高速海上高架和深中通道剪影，见 [03-ROADS-GROUND.md](03-ROADS-GROUND.md)

## 远景天际线

`sz-skyline.js`：

- 北：塘朗山、梅林山的山脊线
- 西：前海、宝安中心区的低精度楼群

- 美团无人机停运，停在站点
- 配色“中国红”加“APEC 紫”；不使用官方会徽图案，只用文字和配色，避免商标问题

## 商圈、景点与公共空间人流（2026-11-09 用户补充）

目标是可辨认的真实场所及人来人往的生活场景。以下地点均纳入待核实、建模和人流验收清单；商场、古城、公园及校园按各自类型建模，不统一处理成商场盒子。

| 场所 | 空间与模型核查重点 | 人流表现目标（模拟，不代表实时客流） |
| --- | --- | --- |
| 万象天地 | 商业建筑群、开放街巷、入口、广场和周边道路 | 逛街、进出入口、橱窗前停留、小组结伴 |
| 海岸城 | 商业体量、裙房、步行空间、连通关系与入口 | 商场进出、步行穿行、广场停留 |
| 南头古城 | 真实街巷尺度、历史建筑、沿街店面和出入口 | 窄巷双向避让、街边停留、游客结伴 |
| 海上世界 | 明华轮、商业街、广场、水景及步行连接 | 广场聚散、沿街步行、观景停留 |
| 欢乐海岸 | 商业街、水岸、广场和真实步行路线 | 沿水散步、商业街往返、公共空间停留 |
| 市民中心 | 大屋顶、建筑基底、中轴公共空间和广场入口 | 广场穿行、游客停留、入口集散 |
| 会展中心 | 先按福田会展中心核对，包含展馆体量、入口及周边公共空间 | 日常人流与展会情景分开；活动情景模拟集散，不虚构实时展会 |
| 人才公园（包括用户已确认的深圳湾文化广场） | 湖岸、步道、广场、绿地；深圳湾文化广场身份已由用户确认，轮廓、各体量外高、屋顶通路及入口仍需核实，不能以其他馆替代 | 环湖散步、跑步、观景、艺术馆入口停留与进出 |
| 莲花山公园 | 真实地形、登山步道、入口与公共活动空间 | 登山、散步、跑步和平台停留，脚步贴合真实坡面 |
| 深圳湾公园 | 分段核对滨海步道、入口、绿地、水岸及慢行分区 | 散步、跑步、观景及慢行避让，不进入红树林或水面 |
| 深圳大学城 | 核实各校园建筑、公共道路、入口及开放边界，不与深圳大学其他校区混淆 | 教学与生活节点间步行、骑行及公共空间停留；不臆造开放通道 |

### 实现与真实性要求

- 先核实每处场所的来源对象、边界、建筑形态、入口和可行走网络，再布置人群。新增地点若超出现有数据覆盖，应列入扩区和数据任务，沿用原坐标原点；不能挪进已有地图或在空白地块摆一个替代模型。
- 人流沿人行道、广场、步道及合法过街连接形成起点、目的地和停留点；密度按场所和模拟时段配置，采用固定随机种子。无客流数据时明确为模拟参数，不能写成真实人数或实时客流。
- 人群具备结伴、错身、排队或短暂停留等差异；避免所有人同速同向、整齐重复动作。仅在有可通行内部空间时让人物进入室内，否则在入口遮挡区合理衔接，不能直接穿墙或在视野中央消失。
- 近处保留步态、脚部接地、转向和衣着材质，借鉴纽约人物系统；用武汉的真实轮廓和建筑分段组织场所。远处采用细节分级、实例化及分区更新，按性能预算逐步调节人数，不预设全城同时满密度。
- 行人和车辆遵守 [碰撞与乘坐规则](07-VEHICLES.md)。密集场所避免人群互相穿透、堵死出口；屏幕外简化模拟不得造成近处人物突然重叠或跳变。

### 验收

每处保存真实资料及核实日期、场所模型与周边关系截图、步行路线和人流演示记录。至少观察一段连续进出和停留过程，实走主入口与人流交汇点，检查近远景切换、车辆让行、地面接触与性能。新增地点默认未完成；既有地标模型完成不等于人流完成。深圳湾文化广场的位置绑定、尺寸及可通行结构未核实前保留明确缺口。

## 纽约经验的统一落地规划

树木与行人共同采用[12号协同规划](12-URBAN-FABRIC-PLAN.md)的源对象、占用边界和可行表面；人群先有真实可通行路径再生成，人数与时段明确为模拟。禁止为填满画面向道路、入口、建筑和湿地随机加树或加人；验收包含绿地与地标的分层关系、近远切换及实际通行。

## 公园运动场与活动设施（2026-11-09）

新增篮球、网球/羽毛球、足球、跑道及健身/儿童活动区的源对象清单和样板计划。核实场地边界、方向、铺面、标线、器械、围网、门洞、灯杆、所在层和权限后建模，不在公园空地随机填设施；运动行为在场地/出入口通行通过后接入。详见[12号规划第9.5节](12-URBAN-FABRIC-PLAN.md#95-公园球场及活动设施)。人群出现、对象池与按可用空间分配密度的规则见[第10节](12-URBAN-FABRIC-PLAN.md#10-行人与车辆的出现和密度)，数字明确为模拟而非实时客流。
