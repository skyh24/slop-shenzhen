# 住宅楼高覆盖与别墅外观

2026-11-19，本轮以建筑 worktree 城市包为对象进行全包核查和局部浏览器查看；不代表逐栋真实高度或全城通行验收。

## 楼高覆盖

检查了 2,057 个具名住宅小区、31,374 条相关楼体记录。原有规则只给已经识别为住宅的主体应用小区估高；小区内 `building=yes` 的具名住宅楼栋仍可能进入普通近邻估高，明确标为宿舍的建筑也可能先被校园公共区域低矮默认值截住。

西组团社区有 37 栋 OSM 明确标注 7 层，沿用 22.4 米，不改成 30 层。9 栋 `way/1426521426` 与 27 栋 `way/1426521427` 原标用途未知，均估为 10.2 米；本轮识别为住宅，并参考同小区相近足迹面积的来源样本，改为 22.4 米估值。海棠阁 `way/1426521430` 的来源 7 层不变。

通用规则：

- 具名住宅小区内，已有至少三个来源住宅同伴、楼名具有住宅楼栋特征的中等以上普通轮廓，可补充住宅用途判断；不据小区边界把所有无名轮廓或附属小屋提升为住宅。
- 缺少来源高度和层数的住宅主体，优先参考同小区面积在自身一半至两倍之间、至少三个有来源高度的住宅样本中位数；样本不足时仍按小区 ID 共用 30–35 层估值，每层 3.2 米。
- 明确住宅用途的校园宿舍沿住宅近邻样本规则估高，不再一律使用公共建筑低矮默认值；学校等公共建筑仍受保护。
- 已有来源高度、来源层数、预测高度、低层住宅标签、历史建筑、内院及明确架空部件继续保留。估值不写成来源层数。

对照前后包，1,796 条原估高记录的高度改变，有来源高度的记录零变化；252 条使用小区同伴估高，5,711 条使用 30–35 层后备值。源 ID、足迹和非建筑顶层内容未改动。当前仍有 11,556 条具名住宅区内的无用途估高轮廓，包含小屋、附属设施与补充轮廓，不能称为 11,556 栋漏建高层；逐栋用途和真实楼高仍是资料缺口。完整分类计数及未知身份清单由构建器写入 `build-report.json` 的 `residentialHeightCoverage`。

## 别墅模型

从低层独栋、半独栋、联排住宅标签及具名别墅区内的适用足迹识别 1,160 条别墅记录。来源明确的两层等楼体沿原模型，不改写成三层；适用的三层及无层数别墅使用独立 `villa` 外观。无高度者以 11.4 米作为三层及屋顶总高估值，来源高度保持原值。

独立别墅按稳定 ID 选择两坡顶、四坡顶或带平台折坡顶；沿原足迹裁分，坡顶最高点不超过包内楼高，三层墙面拟合实际檐口高度。有相交邻楼的体块先保留平顶，避免新的屋顶相互穿插；近景不再叠加高楼女儿墙和屋顶设备。形态、颜色与三层默认值为设计估计，不是逐宅实测。

显示与接触读取同一组 Float32 顶面三角形，斜屋顶碰撞沿用已有三角棱柱截面规则；墙体碰撞止于檐口，坡顶不会变成一整块不可见方盒。内院孔洞保持开放。

## 核查边界

定向检查共 46 项通过、零跳过，覆盖小区同伴规则、校园宿舍、来源保护、三种屋顶、内院及普通建筑装配后的显示/接触/斜顶碰撞。

全量 Node 904 项中 898 项通过，6 项失败在改动前快照（包含原有未提交控制器改动）复现：启动预加载路径、桥栏旁登车、开放店面、文化广场、有色大厦和超级总部。Python 206 项初跑两项受沙盒端口限制，其对应本机服务模块三项重跑全部通过。新增装配测试另随定向检查通过。

浏览器抽看鲸山别墅三种屋顶和西组团体量；内置浏览器超时后转备用浏览器。样段图像与对照脚本保存在忽略目录 `docs/qa/residential-types/`。尚未逐栋核实外观、实走院落或连续实飞全城。
