# 商圈范围与铺装叠置审计

用深圳城市包核对来源范围、样区覆盖、实际输出及几何叠置，供区域计划 R1 选样和重建前后审查。数据契约和道路围合规则见 [27 号计划](../27-REGION-DATA-PLAN.md)。来源对象来自 [城区基准清单](../../data/source/urban-datum.json)。

## 运行

使用项目 Python 依赖（Shapely）和 Node.js。从仓库根目录执行：

```sh
.venv/bin/python tools/sz/audit_commercial_paving.py
.venv/bin/python tools/sz/audit_commercial_paving.py --package /path/to/current.json.gz --baseline /path/to/previous.json.gz
```

省略 `--package` 时读取正式入口的 `js/sz-city.json.gz`。对照两包时，使用同一份范围清单和当前 checkout 的沥青裁切逻辑，以便比较数据差异。可用 `--manifest` 指定另一份同结构清单。报告写到标准输出，包含压缩包和清单 SHA-256、清单声明的 OSM 快照 SHA-256、逐对象与几何并集的统计；两包对照另有面积增量。两份输入均只读。

## 统计口径

- 源范围用项目坐标投影，保留孔洞。样区相交面积用每个包记录的 `terrain.processing.urbanDatum.pilots` 核心范围；更早的包没有此字段时计为 0。
- 铺装取包内 `terrainSurface` 的索引三角面，三个顶点均为 `kind=3`。沥青取同一包的路网和地形，通过 `createRoadSurfaceLayout` 生成进入渲染批处理前的地面沥青三角面；保留已核断面和路口裁切。建筑使用同一包的足迹环，解开分米差分，修复量化后自交仅用于量面积。
- 在水平 XZ 平面求各类几何并集与交集。沥青和建筑各自统计，重叠可能重复计入两个列；跨源范围的总计用并集。建筑按足迹投影，未扣架空层。重叠说明地表图层在平面上叠置，实际开放、入口、净空及通行需现场复核。
- 面积显示到 0.01 m²，精度受原始范围、建筑分米量化、道路断面估计及三角顶点精度影响。当前地形格距 25 米，面积统计基于实际输出三角形的边界。
