# 新洲路墙面闪烁与全包共边候选

日期：2026-11-13。用户截图位置：新洲路—红荔路、第壹世界广场附近。仅调查、验证和规划；未修改生产代码或重建数据。

## 结论

截图附近两组建筑存在与铜鼓路相同的重复外墙生成问题。当前 `sz-building-envelope.js` 的 `REVIEWED_GROUPS` 仅包含铜鼓路和 COCO Park 两组，本次对象不在其中。原修复具备裁切能力，但覆盖范围尚未扩展到这些对象；不能据此判定原样区修复退化。

本轮使用实际城市包、正式 `buildCityBlocks`、`buildingPlacement` 和 Three.js Raycaster，在局部诊断页确认两组共三对对象的重复墙面。每对取一段真实共边，在实际世界高度重叠范围的25%、50%、75%位置采样，均命中两套不同对象的墙；临时将它们交给已有外表面裁切机制后均变为单命中。较宽视角截图显示左侧条纹混合及右侧低层立面混合随对照消除。

这确认了局部生成器中的原因，尚不等于正式场景驾车连续移动验收；本轮未逐一确认全城所有闪烁表现。

- 基线 HEAD：`17b09b1`。工作区另有相机、地图、无人机、界面及交接文档改动，未触碰这些生产改动。
- JSON包 SHA-256：`e461dfd39b2b54ed724c75a50cbda7ff805b0cf58722d9332a919b75e3595015`，共76,022条建筑记录。
- 扫描有效轮廓，条件为精确共边至少1米、平面重叠面积至少1平方米、相对底高/楼高区间重叠至少1米。12条无效轮廓跳过，保留为独立数据问题。
- 得到 **487对候选，涉及770个不同源ID**；没有同ID配对。其中6对属于已有两个裁切组，481对不在现有组中。330对达到较小面99.9%以上覆盖，其他为部分交叠。
- 487是几何候选数，不是487处正式场景故障。27对涉及地标标记，可能已经由专模替换；全包初筛没有统一核实际基底、地标 skipIds、全部近景设施或特殊基础。普通邻楼仅相切、没有面积交叠时被排除。
- 本轮八对对象的24个正式生成器采样点确认双层墙，临时分组后全部单命中。除了既有6对、此次验证8对，其余473对未逐对象做生成器/运行场景判定。
- 这次只检查精确共边；微小错位、近似平行、重复面内细节、阴影或程序化细线采样导致的闪烁不包含在487对里。

## 证据与限制

本地 `docs/qa/xinzhou-flicker-20261113/`：

- `scan.py` / `scan.json`：可重跑的全包几何初筛与完整候选。
- `samples.json` / `osm-tags.json`：八对对象、实际共边段与源标签。
- `probe.html`：直接调用当前正式建筑模块的局部场景，简化天空、阴影、街景；不是正式入口。
- `rays.mjs` / `rays.json`：成对对象的实际放置高度及前后三高度射线。命中距共边目标点误差允许2毫米，并要求不同对象种子；两次执行均为24处双命中变单命中。依赖活动浏览器诊断页，复用时需更新任务空间ID。
- `wide-original.png` / `wide-grouped.png`：同机位局部外观对照。临时分组顺序用于诊断，不代表已经裁决真实外墙材质。

正式入口尝试在“生成建筑”阶段超时；按现有 QA `skip=blocks,...` 降载的一次恢复遇到 `cityBlocks.surfaces is not iterable`，因此转为直接调用正式生成器的最小场景。该 QA stub 接口问题单列，不能解释用户截图的闪烁，也不把局部场景当作正式启动通过。

诊断页所有对照几何已经释放，原始几何可见性已恢复；任务浏览器正常关闭，本轮8086服务已停止。原始代码与双包未修改。

## 修复规划

1. **先扩到两组已核样点。** 复核当前包及对象，将银杏阁/丹桂阁组和第壹世界广场组接入已有外表面裁切；不能只删除大轮廓或简单抬高塔楼。确定共享外墙的立面优先级，保留低层露出部分、院落、底面及屋面，不把诊断排序当作真实材质依据。
2. **形成可维护的对象关系清单。** 源ID、几何关系、证据、覆盖高度、共享墙所有者、审核状态和例外进入可审计资料。迁移目前JS里的两个固定组，避免每发现一处就散落新增硬编码。运行时仍使用已有有限组裁切，避免逐帧全城两两求交。
3. **分层处理481对未纳入候选。** 先排除专模替换、不同实体高度层、桥/屋盖和特殊基础；对实际渲染共面、相同外向且高度重叠者生成确认清单。完全重复记录与塔裙/部分重叠分别处理。未核实关系留为候选，不凭二维相交批量合并。
4. **保持同源接触。** 外墙、封顶、底面、近景细节、碰撞与可站屋面共享组合体量规则。复核两个分块跨界、低层顶部穿入塔楼、多个部件相接及移除内部顶面的行为；已有铜鼓路/COCO Park维持回归。
5. **覆盖范围扩大但控制成本。** 离线空间索引筛候选，候选更新有差异报告；接入建筑生成时只处理邻接小组。记录构建耗时、启动耗时、三角形、绘制次数和包增量，不能通过关闭立面、远景或降低全局清晰度消除症状。
6. **先几何后连续画面验收。** 每个已确认对象至少三高度、内外侧射线，重叠范围内只留一层外墙，上部、屋顶和合法架空完整。新洲路真实驾驶前进/倒车、停住环视、步行及远近切换，覆盖金色/正午/蓝调。另选至少两个独立区域确认，给出已修/误报/保留未知数量。几何消除后残留闪烁再单独排查阴影、细线采样和LOD。

按25号选择 `buildings` 与实际受影响的检查，数据变更才走唯一构建入口；若涉及共享核心则走全量。当前只形成研究和实施边界，T7修复未执行。
