## 1. 核查方法与坐标口径

- 检索工具：`web_search` / `web_fetch`。直接读原始页面，不采用搜索摘要。
- 来源等级：① 政府网站 / 政府公报；② 运营方自有新闻页；③ 党媒或主流媒体；④ 本地生活媒体（本地宝等）。第 ④ 级只用于补足开航年月，不用于判定"现在是否在飞"。
- 一个真实条目至少要能回答：**谁在飞、飞在哪个公开区域、端点怎么描述、谁说的、什么时候说的**。任一缺失就降置信度。
- 坐标口径：全部 **WGS84**，取自 OpenStreetMap（Nominatim 检索，2026-11-09）或仓库已核实的 [`data/source/landmarks.json`](../../data/source/landmarks.json)（OSM 对象 ID + 2026-11-08 快照）。
- **不得混用坐标系**：高德、腾讯地图等互联网地图在国内是 GCJ-02，与 OSM/WGS84 有几百米级偏移；项目原点与地标都建立在 OSM/WGS84 上，**不要拿地图 App 截图上的坐标直接填 `air-routes.json`**。
- 项目坐标换算（本文一律标"近似"）：

  ```
  x = (lon - 114.0545) * 102800     # 东为正
  z = (22.5463 - lat) * 110600      # 南为正
  ```

  该换算在深圳纬度上偏差约千分之一量级，**只用来说明"在框里哪个位置"**，不能当测绘成果。OGC 精确换算（Web Mercator 或 UTM 50N）与它的差异在 1.5 km 尺度上小于 1 m，不影响判断，但正式数据管线仍应走既有 UTM/局部投影实现。

一期范围（用于判断条目在不在漫游范围内，见 [docs/00-SCOPE.md](../00-SCOPE.md)）：

### 2.6 大疆天空之城：不可用

检索"大疆 天空之城 + 无人机/配送/航线/起降"，只得到建筑本身（竣工验收、设计解读、测试飞行视频）与泛低空经济报道，**没有**任何公开的运营航线、起降点或示范航线证据。

- 结论：天空之城只按地标建模（[`data/source/landmarks.json`](../../data/source/landmarks.json) `dji-sky-city`），**不得**在其周边编造"大疆示范航线"。
- 佐证（仅说明该楼存在，不说明有航线）：[新浪乐居转载 天空之城通过竣工验收](https://k.sina.com.cn/article_7517400647_1c0126e4705903jfd6.html?from=estate)

## 4. 不能公开核实、禁止编造的部分

以下内容在公开来源里**没有**，任何"补全"都等于虚构。数据里应留 `null` 或显式 `estimate`，界面上要能让用户看出来。

1. **逐点航迹 / 航路走廊**。没有任何运营方公开过配送航线的折线坐标。只能做"连接两个公开端点区域的示意折线"，明示"示意"。
2. **配送巡航高度**。中文公开报道里没找到任何一条给出美团/丰翼配送无人机的巡航高度数值。本文建议值必须在数据里写 `cruiseAltitudeSource: "estimate"`。
3. **起降柜 / M-Port 的精确位置**。除 OSM 那个命名节点外，全部只有"某商场/某公园"级描述。**不能用公园中心点冒充取餐柜**。
4. **医疗与病理运输的机构端点**。血站—医院航线有机构名但在一期框外；病理标本通道连医院名都没公开（"医院天台 → 区域临床病理诊断中心"）。
5. **口岸与边境敏感区**。福田口岸、深圳湾口岸、福田保税区一带涉及边检与管制空域，**不做航迹、不做穿模飞行、不做"无人机从口岸起飞"的画面**；只允许站点标签。
6. **APEC 相关安保空域与临时管制细节**。公开的只有第 5 节那份通告的时段与范围，**具体禁飞边界、警力部署、临时雷达/反制设施不可考**，不要画任何"安保空域"几何。
7. **大疆天空之城是否有内部测试航线**。无公开证据，禁止推定。
8. **"南山 26 个点位""每周演出""常设无人机表演场地"** 这三类说法都无法用可引来源支撑（见 2.5、2.7）。
9. **建筑体量/高度与航线的避让关系**。本文给出的"低于春笋一半"只为画面安全，**不是**运营方的避障依据。
