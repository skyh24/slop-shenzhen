# 日常检查与交付

选能覆盖本次改动的最小检查，做一次差异审查后提交。修具体问题时，优先点测对应文件；模块涉及多处时，使用下表的快速检查。只有改动跨越多个模块的行为边界时才合并范围。

| 范围 | 默认检查的关键结果 |
| --- | --- |
| `controls` | 四模式切换、乘员跟随、受阻时保留原位置与模式 |
| `roads` | 道路贴地、弯道与路口接续、无效桥面留空、分隔带保留 |
| `buildings` | 以市民中心验证源楼绑定、屋面与柱廊的实际几何和净空 |
| `street` | 公共步道有承托、绕障维持通行、中心二路样段连续 |
| `ui` | 首帧或加载失败反馈、地图点选、拖动与图层命中 |
| `air` / `shows` | 空中巡游的换速与停止；节目的播放、会话切换与退出恢复 |
| `data` | 读包失败与重试、编码精度、损坏及来源不匹配被拒绝 |
| `tooling` | 测试选择与失败报告、开发服务器刷新与错误响应 |
| `docs` | 检查差异空白，另核改动的链接或事实 |

```sh
python3 tools/qa/check.py --scope ui
python3 tools/qa/check.py --node tests/sz-tunnels.test.cjs
python3 tools/qa/check.py --python tools/sz/tests/test_roadgraph.py
```

`--list` 可预览选择。点测可独立运行，也可附加到模块检查，重复文件只执行一次。Node 使用项目锁定的 Three.js，Python 使用 `.venv`。结果、耗时与失败日志在本地 `docs/qa/checks/`。

## 交给用户体验

界面或场景可见变化，复用当前检出的本地服务，或运行 `python3 tools/sz/serve.py --port 8080`。在内置浏览器打开[本地场景](http://127.0.0.1:8080/)，确认加载层退出和目标界面可见，将页面停在用户要体验的位置。交付时给出链接和一句操作提示，保留页面与服务。外观需要对照时，附一两张关键位置截图即可。

截图记录画面。路线、碰撞、按钮行为等实际操作单列已测范围，交给用户体验的部分保持待验。仅修改工具或文档时，按需打开页面。

共享核心、格式或坐标变化、大版本及正式发布运行 `python3 tools/qa/check.py --scope full`。冷热启动、固定路线和稳定性采样按[正式验收标准](10-PERF-QA.md)执行。正式里程碑在全部相关条件达标、更新 HANDOFF 和 TASKS 后提交、推送并打 `baseline/m<N>` 标签。
