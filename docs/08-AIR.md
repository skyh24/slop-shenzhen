# 配送无人机

场景展示两组配送端点。人才公园潮汐广场与海岸城商圈有历史开航资料，中心公园 C2 与莲花山的配对仍待核。每组分别记录站点、端点配对、航迹、高度、时间窗和核实日期。场景按记录的时间窗展示停运，航迹、高度和飞行速度含模拟参数。[航线清单](../data/source/air-routes.json) · [来源卡](research/drone-routes.md)

| 组件 | 职责 |
| --- | --- |
| `js/sz-drone-routes.js` | 从端点和区域数据生成往返轨迹、货机姿态、站点与停运状态。模拟绕行使用场景净空。 |
| `js/sz-drone-watch.js` | 地图选站后跟拍配送过程，支持调速、拖动取景和退出恢复。 |
| `js/sz-vehicles.js` | 程序化货机模型。玩家四旋翼由[载具控制](07-VEHICLES.md)管理。 |

验收覆盖起降、两端接近、往返、净空、停运日界及跟拍退出。人才公园的编队表演按独立的[节目规格](LIGHT-SHOW.md)运行。
