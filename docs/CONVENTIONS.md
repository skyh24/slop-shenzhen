# 开发规范

## 代码

- ES Module；import 放顶部，两空格缩进、单引号、分号。必要循环依赖例外须解释原因。
- three.js 从 `index.html` import map 取，锁定 0.187.0；不加打包工具或 npm 运行时依赖。
- 文件按职责、复杂度与可维护性决定是否拆分，不设行数上限，不为行数拆文件；`js/main.js` 主要负责初始化、模块装配与运行调度。
- 有限取值 switch 的 default 抛错。随机过程使用实体固定种子。
- 对话、文档、新注释中文；标识符、日志、报错、测试名、提交信息英文。界面文案集中到 `js/sz-strings.js`。

## 坐标与数据

- 原点 `114.0545E, 22.5463N`，米制，x东、z南、y上；扩区不改原点与已有实体 ID。
- 角度用弧度。地理方位以北为0、顺时针；控制器 `x=sin(h), z=cos(h)`，0为南。接口使用 `headingFromBearing` / `bearingFromHeading` 转换。
- 原始文件放 `data/raw/`；人工核对与快照清单放 `data/source/`，记录地址、日期、哈希、对象 ID、许可、基准与不确定性。
- 事实优先于模板；没有证据的值保持未知。采集时间、产品发布时间与核实时间分别记录。遥感预测和层数推算不称实测，同上游数据不算独立复核。
- 地标身份以 `landmarks.json` 为准；名称/距离只生成候选。楼高裁决见 [数据管线](02-DATA-PIPELINE.md)。运行时不联网拉地理数据。
- 生成文件只经 `tools/sz/build.py`；同一时刻由一个执行者重建两个包及报告，不手工合并二进制冲突。

## 几何与场景

- 程序化建模，不导入 glTF；车辆不带品牌标志或品牌名；APEC 只用文字和配色。
- 显示、碰撞、导航和脚/轮接触共用活动表面；架空层、连桥、柱廊分段建实体。摆放避让范围与物理碰撞范围分开。
- 楼体相对高度、地面绝对标高、屋面和平台高度分别处理。DSM 包含树冠/屋顶回波；派生工程面明确标记，不能当作裸地测量。
- 保留有来源的山体起伏与公共空间；范围外高程返回未知。不能移动建筑、缩路或虚构坡道掩盖冲突。
- 真实入口与开放权限需独立证据；POI、楼名牌或场所中心不等于可通行入口。装饰几何不会自动获得通行资格。
- 重复对象按核实 ID 替换，保留邻楼和内院；树、车、人、无人机等重复对象优先实例化，资源随分块释放。

## 工作边界

`ref/` 只读；密钥、本机绝对路径、`data/raw/`、`.venv/`、`docs/qa/` 不入库。默认 main 开发和提交；分支/工作树须用户明确要求。流程以 [开发检查](25-FAST-CHECKS.md) 为准，验收以 [10 号](10-PERF-QA.md) 为准。
