# 09 界面与玩法

## 移动方式

| 键 | 方式 | 纽约对应 |
| --- | --- | --- |
| `1` | 步行 | person |
| `2` | 开出租车 | car |
| `3` | 骑共享单车 | cyclist |
| `4` | 四旋翼载人飞行器 | helicopter |

## 界面

**沿用纽约原版 `index.html` 的结构、元素 ID、布局和快捷键**，只把文字换成中文、内容换成深圳。逐项对照表见 [11-MVP.md](11-MVP.md) 第 3.6 节。MVP 的 `mvp.html` 右侧按钮面板不保留。

- 全部中文，文字集中在 `js/sz-strings.js`
- 当前地名显示“区 · 路名”，例如“南山区 · 科苑大道”
- 速度单位 km/h
- 顶部工具栏：四个时段、传送、地铁菜单、APEC 主题、地图 `M`、声音 `N`、隐藏界面 `H`
- 地铁菜单：弹出列表，每条线一个官方颜色色块，逐条勾选，另有高铁线路一项；**默认全部不显示**，状态存 `localStorage`（详见 11-MVP 第 3.4、3.5 节）
- 左下小地图，点开全图；底部移动方式切换和每种方式的键位提示
- 手柄和触屏摇杆原样保留

## 地图（`sz-map.js`）

- 画陆地、海、道路、建筑、公园
- 地标图标，点一下传送
- 搜索框：可以搜地标名、路名（拼音首字母也能搜，例如 `sndd` 找到深南大道）
- 可以开关无人机航线和地铁线路（线路用官方颜色）
- 纽约原版的指北针、缩放、回到玩家、看全图、悬停信息、计数都保留

| 键 | 机位 |
| --- | --- |
| `8` | 深圳湾公园看后海天际线 |
| `9` | 市民中心广场看中轴线和平安大厦 |
| `0` | 人才公园湖面看春笋 |

## 出租车接单（参考武汉 `TAXI.md`）

- 开出租车时按 `T` 打开接单
- 系统在 300 到 800 米外的人行道上放一位乘客，地图标出
- 停在乘客旁边 6 米内且车速低于 1 m/s，乘客上车
- 目的地从传送点和主要路口里随机挑，路线由路网最短路径算出，地面画导航箭头
- 到达后结算：里程费（起步价 10 元含 2 公里，之后每公里 2.7 元）加时间评分
- 记录累计单数和收入，存在 `localStorage`

## 存档

- `localStorage` 键名 `sz-player-state`，存位置、朝向、移动方式、时间
