# 05 地标

## 做法

- 每个地标一个文件：`js/landmarks/<id>.js`，导出 `build(ctx)`
- `js/landmarks/index.js` 读 `GEO.landmarks`（数据管线从 OSM 按名称或对象 ID 找到的轮廓、中心、朝向、占地），把模型对齐到真实位置
- 模型用 three.js 基础几何体加 TSL 材质拼出来，不导入外部模型，和纽约原版一致
- 每个地标返回碰撞盒，供人物和车辆使用
- 高度用 `data/source/landmark-heights.json` 里核实过的值

## 对位规则

1. 优先用 OSM 对象 ID（写在 `data/source/landmark-heights.json`）
2. 没有 ID 时按名称匹配，取距离 `00-SCOPE.md` 坐标最近的一个
3. 轮廓偏离文档坐标超过 300 米时报警，不自动对位

## 验收卡片

每个地标完成后在 `docs/landmarks/<id>.md` 写一张卡片：

- 参考照片或者参考资料来源链接
- 真实高度和模型高度
- 两个固定机位截图：白天、夜晚
- 已知差异
