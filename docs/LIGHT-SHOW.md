# 灯光与无人机节目

| 场景 | 内容 | 实现（相对 js/） |
| --- | --- | --- |
| 福田楼宇夜景 | 普通高楼使用立面灯带与屋顶轮廓灯，专模从已有结构提取巨柱或边缘灯带。灯带随昼夜变化，装饰网格不参与碰撞。 | `sz-light-show.js`、`sz-day-phase.js` |
| 莲花山灯光展 | 从山顶平台观看福田楼群，原创节目按片段控制楼宇窗格和色彩。 | `sz-lianhuashan.js`、`sz-cbd-program.js` |
| 人才公园无人机秀 | 从滨水观演区观看《后海星潮》，编队按节目时钟切换图案。 | `sz-talent-drone-show.js`、`sz-drone-choreography.js` |

两个观演节目共用播放面板，支持暂停、继续、重播、1×/2× 和跳到下一段，末段跳回开场。切换节目保留首次进入前的相机和时段，退出时恢复。进入条件与互斥规则见[观察会话](09-UI-GAMEPLAY.md#观察会话)。

节目的内容、配色与节奏均为项目原创展示。验收分别观察机位视线、完整节目周期、切段与退出、日夜材质和稳定帧时。真实场次、时刻表和楼宇参与范围须有独立来源。
