# 20 楼高与周边建筑核对（2026-11-09）

用户要求：检查楼高是否跟真实高度对应，看看周边建筑，并参考真实图片。

## 1. 方法和数据

- 我们的数据：共享包 v2（合并主分支过滤后 36,064 栋），楼高来源仍按 [02-DATA-PIPELINE.md](02-DATA-PIPELINE.md) 的优先级：OSM 米制高度 → OSM 层数 × 3.2m → Overture → GloBFP → 按类别和面积的估计。每栋楼保留 `heightSource`。
- 对照资料（2026-11-09 读取）：
  - 中文维基百科 [深圳摩天大楼列表](https://zh.wikipedia.org/wiki/深圳摩天大楼列表)（已完工 150m+ 列表，含尖塔/顶楼口径）
  - 英文维基百科 [List of tallest buildings in Shenzhen](https://en.wikipedia.org/wiki/List_of_tallest_buildings_in_Shenzhen)（含坐标，可和我们的楼按距离匹配）
  - 具体项目页：[深圳东海商务中心](https://zh.wikipedia.org/wiki/深圳东海商务中心)、[信息枢纽大厦](https://zh.wikipedia.org/wiki/信息枢纽大厦)、[深圳湾超级总部基地](https://zh.wikipedia.org/wiki/深圳湾超级总部基地)
  - 参考照片：Wikimedia Commons，作者 Charlie fong，CC BY-SA 4.0；文件名和对比图见第 4 节。照片只作本地对照，不提交进仓库。
- 口径：对照值取公开资料的总建筑高度（含尖顶，不含天线）。我们这边大多数 OSM 值同口径；少数字段是顶楼高度，差异会写在下面。

## 4. 和真实照片的对照

参考照片都来自 Wikimedia Commons（作者 Charlie fong，CC BY-SA 4.0），只下载到本地 `docs/qa/realism/` 做对照，不提交。

| 对照图 | 真实照片 | 我们的机位 |

| `docs/qa/realism/compare-donghai.jpg` | 深南大道/东海 2021 | `?qa=1&cam=-3650,160,1080,-4160,140,790` |

对照结论：

- 福田：平安一枝独秀、周围 250–380m 塔楼的高度层级和照片一致；我们镜头更低更近，前景体量偏大，属机位差异。
- 后海：春笋与右侧 311m、247m 塔楼的高度关系、春茧在右侧的位置都和照片一致。
- 车公庙：东海 A/B 双塔高差（306/261）在修正后和照片一致，招商银行大厦高度正确。
- 画面差异主要来自：街区细节、地面和绿化（P0 地面问题）、以及下面列出的入库缺口，不是楼高数值。

## 5. 发现的缺口（本轮不硬改）

| 问题 | 证据 | 为什么不直接改 |
| --- | --- | --- |
| 信息枢纽大厦主楼缺失 | OSM 只有 8 层裙楼 `way/241116474`（25.6m），主楼 48 层 240.7m 没有独立足迹 | 缺塔楼足迹，把裙楼直接拉高 240m 会生成错误体量 |
| 联合广场高度只有 64.2m | 公开资料 208m / 52 层；OSM `way/817826928` 是 9,567m² 的大体量，未分塔楼 | 直接改高会把整个大体量挤出成 208m 板楼 |
| 南山科技联合大厦（307.2m）未入库 | 2026 年在建，OSM 无对应命名足迹 | 需要重新提取足迹，不能凭名字补楼 |
| 中洲滨海商业中心 T1/T2（290.8m）未核实 | OSM 没有对应名称记录 | 可能在别处无名部件中，先核实再改 |
| 侨城一号、大中华、卓越后海等 ±4% | 公开资料是总高，OSM 可能给顶楼或含冠部 | 口径不明，不写成实测 |
| 罗湖（京基100、城脉、信兴等）、前海、龙岗 | 公开资料 294–441.8m | 不在一期范围 |

## 6. 复现

```sh
.venv/bin/python tools/sz/build.py
# 构建报告 data/source/build-report.json 的 buildingHeightOverrides 记录应用和未使用的覆盖
node --test tests/*.test.cjs
.venv/bin/python -m unittest discover -s tools/sz/tests
```
