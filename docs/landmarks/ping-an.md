# 平安金融中心北塔与零售连桥

核实日期 2026-11-09。北塔建筑总高 599.1 米，程序模型保留该值。KPF 项目页的 600 米为约数，业主论文区分 555.6 米屋顶、592.5 米主结构与约 599 米塔高。塔顶建筑标高在当前 DSM 锚点下为 Y≈605.15 米。锚点 Y≈6.05 米为北塔足迹包围盒中心的地形采样，实际入口和基础标高仍待测量资料。早期含 660 米尖塔的方案另有记录，本模型按建成照片取形。[CTBUH 建筑记录](https://www.skyscrapercenter.com/building/ping-an-finance-center/54) · [KPF 北塔建成照片](https://www.kpf.com/project/ping-an-finance-centre/) · [业主论文第 2、3、4 图](https://global.ctbuh.org/resources/papers/2969-paper41-v2.pdf)

## 周边核对

业主论文给出的北塔地块由福华路、益田路、福华三路和中心二路围合。运行包可定位福华路 `way/996208013`、益田路 `way/40977700`、福华三路 `way/996752253` 及中心二路 `way/853286944`。独立核对的参照对象包括西侧购物公园、东侧卓越时代广场一期、南塔和更南侧平安财险大厦。该轮只接管表中建筑，南塔上部四个源块、相邻商业建筑、广场边界和路缘细节沿用当前数据。道路断面、公交站、人行过街和退界以正式道路与街景验收为准。零售中庭、连桥屋顶花园与内部上下楼动线仍缺几何和实走证据。

## 画面与通行

- 冷色顶冠和观景段常亮，办公区少量窗光，西门厅暖光。灯光位置参考项目照明团队，强度及窗户占用为显示参数。[照明团队论文](https://global.ctbuh.org/resources/papers/2966-paper44-v2.pdf)
- 数据、分段生成及正式入口已接入。自动测试核对塔高、收分、四角双柱、顶冠开口、西侧雨篷下的净空和福华三路桥下净空。截面切片用同一组渲染顶点，测试覆盖旋转收分体。连桥屋顶接触取自渲染三角面。
- 浏览器达到可见级。从西南侧约 `(-1060, 280, 1400)` 以 52° 视场观察，正午可辨认收分、四角钢柱和切面顶冠，画面裁掉了北塔底座。[正午截图](../qa/m2-ground/ping-an-model-day.png)
- 午夜可见零星办公窗光，实景可辨的冠部和外框轮廓光仍需调整。[午夜截图](../qa/m2-ground/ping-an-model-night.png)
- 西侧入口建议从 `(-488, 10.8, 1069.7)` 向 `(-449, 16, 1069.7)` 观察。补拍街区全景、入口近景和沿街行进机位，实际步行与车辆过桥底待验。
