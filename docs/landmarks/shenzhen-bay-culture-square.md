# 深圳湾文化广场

核实日期 2026-11-09。用户所指的“人才公园附近的新艺术馆”已确认为深圳湾文化广场。现用 OSM `way/1441599159` 对位，快照中具名且标为 `building=public`。整体外廓面积约 45,762 平方米，中心约 `(-11758.73, 3462.98)`。运行包原有整体外廓和五个内部体量的棱柱，均用估计高度。程序模型只接管这六个核实过的源对象。[OSM 源轮廓](https://www.openstreetmap.org/way/1441599159) · [MAD 建成项目、平剖面及照片](https://www.i-mad.com/articles/shenzhen-bay-culture-square-completion)

## 模型与周边

- 按体量轴测建立南北两组共九个形体，含北馆竖向主石、倾斜侧体、南馆盘状主石与上方小石。南盘、北端独立馆、北主石、北斜侧体、南独立馆分别用 `way/1441599154` 至 `way/1441599158` 的源平面凸包拟合，其他四个小体量取 MAD 平面和轴测。石体在同源截面间共享法线，拐角按建成照片收圆。北馆向上偏斜，朝湖侧的斜椭圆天窗与白色花岗岩细板缝为照片拟合。南组靠湖小体量沿图平面向南调整约 3.3 米，保持在源建筑轮廓内。[MAD 建成照片与材料说明](https://www.i-mad.com/articles/shenzhen-bay-culture-square-completion)
- 连续绿屋面按源外廓与两处庭院开口生成。盖板高差结合剖面与当前位置 DSM 样点，共边三角面共享法线。沿已配准 MAD 平面取主要环路和支路控制点，步道宽度约 2.6 至 3.5 米，为图面拟合。程序铺装与绿屋面共用同一组顶点。模型保留科苑南路、海德一道、东侧 `way/1436391625`/`way/1436391626` 登良路隧道和人才公园岸线源对象。隧道、下沉空间、屋顶步道和连接城市的天桥仍需分区工程图或实地标高。
- 当前为 3 个材质批次、1,391 个分段碰撞实体和 19,248 个渲染三角形。真实 Three.js 测试核对石体截面顶点和连续法线、庭院开口、屋面三角顶点及步道铺装覆盖率。屋顶步道连续标高和坡面接触尚未核实，当前仅有实体碰撞。验收时需要按连通区域共享面 ID，用真实三角高度核对上坡和跨三角支撑。

## 画面与通行

- 正式入口湖畔机位可见两组白石和覆土屋面。近景候选 `(-11589, 14, 3527)` 向 `(-11747, 24, 3450)`，用于核对广场、绿地与入口关系。入口、滨水步行和屋顶跨桥仍待实际操作。
