# 深圳湾体育中心（春茧）

核实日期 2026-11-09。建筑由佐藤综合计画与北京市建筑设计研究院共同设计，白色网壳包住西侧游泳馆、中部体育馆及东侧海景体育场。实景可辨两馆的银白色实体屋盖、向侧面卷落的斜交网格、大树广场的通天孔、海景体育场的露天椭圆孔及东端海之门观景桥。[佐藤综合计画的全景、广场、近景和夜景照片](https://www.axscom.jp/legacy/en/project/no03341/) · [《深圳市地名志》](https://pnr.sz.gov.cn/attachment/1/1285/1285348/10537364.pdf) · [南山区场馆介绍](https://www.szns.gov.cn/mlns/whns/tycg/content/post_12589347.html)

## 对位和尺寸

| 部位 | 源对象和模型 |
| --- | --- |
| 运动中心场地 | [`way/542049855`](https://www.openstreetmap.org/way/542049855) 为园区范围。用场地内四个已打包建筑对象定位曲面，场地范围继续由现有地面系统使用 |
| 西游泳馆、中部体育馆 | [`way/665408866`](https://www.openstreetmap.org/way/665408866) 与 [`way/665408865`](https://www.openstreetmap.org/way/665408865)。网壳在原足迹内随横截面卷下，内设拟合玻璃围护与椭圆实体屋顶，室内屋顶中心线和局部起伏依据实景和结构示意估计 |
| 大树广场 | [`relation/9244351`](https://www.openstreetmap.org/relation/9244351)。保留内环直径约 19 米的通天孔，网壳按开孔轮廓向中间收落，两侧留出门厅尺度的空间 |
| 海景体育场 | [`relation/9244350`](https://www.openstreetmap.org/relation/9244350)。原内环留空，四层简化看台按西高东低布置，东侧截出海之门。上部为有厚度的曲面环盖，外缘由菱格钢肋过渡至场边。观景桥为起拱楼面、上弦、斜腹杆和两端支座，模型净跨 103 米，桥底与场心均保留净空 |

四个 OSM 外廓合计东西约 514.5 米、南北约 241.3 米。ASCE 工地资料的覆盖范围为约 500×240 米，结构资料给单层网壳 532.7×240.4 米，跨距口径有差异。模型按原足迹对位，钢构件半宽最多延至足迹外 0.5 米。工程资料记录网壳相对落脚点最高约 42.3 米、局部工程落脚标高 +6.0 米，ASCE 工地记录为约 0.7×0.45 米弯扭箱形钢构件。模型按前者控制最高点、后者近似肋截面。斜交间距约 7.4 米、剖面控制点、场馆局部高度和看台尺寸为展示估计，四个 OSM 源高均保留为 40 米。[ASCE 工地技术资料](https://sections.asce.org/greaterchina/Site_Visit_flyer_Shenzhen_Bay_Stadium_Complex.pdf) · [结构研究](https://doi.org/10.13969/j.cnki.cn31-1893.2015.04.006) · [结构示意、分段和观景桥尺寸](https://www.lfspaceframe.com/news/shenzhen-bay-sports-hall-steel-structure/)

模型以露天体育场足迹包围盒中心 `(−11128.85, 2845.65)` 的当前 Copernicus DSM 样本 Y≈5.16 米作为连体钢壳的放置基准，最高 Y≈47.45 米。该取样点位于露天内场，推定的是模型共同标高。当前 DSM 在游泳馆、体育馆及连接处对应中心分别约为 34.42、43.82、31.40 米，受屋顶回波影响，较低构件和地面通路会被同一份显示和接触地形局部盖住。

工程说明将网壳落脚记为 +6.0 米，建设方人员的访谈和现场报道把相同数值用于大树广场二层步行平台。公开资料确认平台与下方车行层分离，仍缺工程 ±0.000 对应的国家高程和露天球场与该平台的实测高差。运行模型暂按球场样本定位，+6.0 米保留原工程口径。西两馆屋架的后续比例核对有可用尺寸，体育馆短轴 104.3 米、长轴 116.9 米、网架深 4.5 米，游泳馆短轴 77.6 米、长轴 98.6 米、网架深 3.5 米。工程网壳平均格边约 4.05 米，大树广场落脚环直径约 20.6 米。[结构说明第 1 节](https://www.lfspaceframe.com/news/shenzhen-bay-sports-hall-steel-structure/) · [华润项目负责人访谈](https://m.fang.com/news/nn/0_6095853.html) · [深圳特区报现场](https://sports.sina.com.cn/o/2011-03-18/09105493719.shtml)

局部地面分离需要两类边界。对已核实的室内封闭建筑，可验证在建筑占用范围内裁掉 DSM 屋顶回波，室内楼面未核实时将其标为未知。显示网格和可接触面使用同一裁切结果，裁切范围外保留原始 DSM。大树广场、架空网壳、露天场心和下沉广场属于不同标高及通行层，需竣工剖面和高程基准或测绘控制点来生成实体地面。屋顶像元还会影响轮廓外的插值，高差接缝和室外坡道需单独核查。

## 周边和验收

周边范围含滨海大道、科苑路、沙河西路、体育中心练习场及深圳湾内湖。西北侧深圳湾木棉花酒店、东侧广场水景和 [场内运动场 `way/493390579`](https://www.openstreetmap.org/way/493390579) 沿用当前独立数据。该轮以屋壳和场馆为主，周边步道、立面改造、海之门显示屏及大树广场的照明细节仍待核实。[设计合作单位项目介绍](https://jzcz.cbpt.cnki.net/portal/journal/portal/client/paper/ddfd5ef4b43621e8185f06033b01790b) · [深圳市政府十五运会场馆改造报道](https://www.sz.gov.cn/cn/xxgk/zfxxgj/zwdt/content/post_12429098.html)

南水岸空中机位建议约 `(−11190, 145, 3330)` 向 `(−11276, 23, 2830)`，东侧海之门约 `(−10960, 20, 2860)` 向 `(−11131, 25, 2848)`，另从北边看沿线屋顶收放和广场关系。夜景目前表现钢格与屋面，不同区域的灯光和十五运会改造后演出效果有待实景对照。

四个源对象已接入正式入口。浏览器从南水岸约 `(−11190, 145.03, 3330)`、55° 视场可见白色网壳和露天场心。西侧两馆被 DSM 屋面回波局部遮挡，尚未通过整体实景验收。[正午截图](../qa/m2-ground/chunjian-model-day.png) · [午夜截图](../qa/m2-ground/chunjian-model-night.png)

自动测试验证壳顶高、封闭厅体足迹、双向斜肋、两处透空及观景桥下净空。当前用斜梁和三角棱柱的同一组顶点生成渲染与碰撞，观景桥上表面参与同面接触。广场与海之门的浏览器实走、东西两馆入口和邻街通行未验。
