# 市民中心参数卡

源身份见 [landmarks.json](../../data/source/landmarks.json)，模型`js/sz-landmarks/civic-center.js`。本卡保留现有测试读取的参数说明；状态统一见 [HANDOFF](../HANDOFF.md)。

公开资料：屋盖约486×154米，中部最窄约120米；风洞研究约80米曲面顶高，地名志主体含顶84.7米。OSM双塔91.5米与屋盖66米标签口径不同，保留冲突，不混作同基准测量。模型使用屋盖相对基底约80米、整体最高84.7米，斜顶与部件尺寸含估计。

[风洞研究](https://www.techno-press.com/papers/20373) · [深圳市地名志](https://pnr.sz.gov.cn/attachment/1/1285/1285348/10537364.pdf) · [承建方资料](https://2bur.cscec.com/xwzx6/qykw6/201810/P020181022582902814473.pdf)

- 绑定OSM十块屋盖、带孔翼楼`relation/10837976`/`10837977`、基座`10837978`及双色塔；保留四处采光孔与通透中跨。
- 横肋间距 27 m；檐口收边板宽 0.8 m、深 1.3 m；均为模型拟合参数，不是实测。
- 两翼各 17 组树状柱；柱位、截面、分枝为估计，分枝顶接屋盖下皮，接触量 0.1 m。
- 肋、檐口、柱廊共用`roofPanelPart/spanPart/loftPart`实体；高度查询取实际屋盖三角面。柱廊位置/节点、细板缝与灯带资料仍需核对，任务归T7。
