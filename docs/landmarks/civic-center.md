# 深圳市民中心

核实日期 2026-11-09。大屋盖长 486 米、最大宽 154 米，公开风洞论文记录中央最窄处约 120 米、结构厚度 2.25–9 米、从地面到曲面顶约 80 米。《深圳市地名志》给出中区主体含屋顶 84.7 米。承建方回顾也提到 84.7 米，称为“大屋盖顶高”，未附基准与具体测点。PBF 里两色塔均标 91.5 米，屋盖中央最高标签为 66 米。这些数值的对象范围和标高基准无法完全对齐，均保留原口径。模型把 80 米用于大曲面最高点、84.7 米用于整体最高点，双塔各自的斜顶尺寸为外观估计。以中区基座轮廓包围盒中心的当前 DSM 样本 Y≈8.26 米作屋盖标高基准，模型曲面最高 Y≈88.16 米、塔顶 Y≈92.96 米。[风洞研究](https://www.techno-press.com/papers/20373) · [同一论文正文，第 3 节](https://www.researchgate.net/publication/263623066_Large_Eddy_Simulation_of_wind_loads_on_a_long-span_spatial_lattice_roof) · [《深圳市地名志》页 866–867](https://pnr.sz.gov.cn/attachment/1/1285/1285348/10537364.pdf) · [中建二局承建者回顾，2 版](https://2bur.cscec.com/xwzx6/qykw6/201810/P020181022582902814473.pdf)

## 周边与验收

北向核对市民中心、图书馆与音乐厅、当代艺术与城市规划馆、书城和莲花山的轴线。南向核对市民广场 [`way/183106112`](https://www.openstreetmap.org/way/183106112)、福中三路及深南大道。建议三机位均从真实地形或明确飞行机位取景。北侧轴线空中约 `(1, 160, -480)` 向 `(1, 41, 0)`，南广场约 `(0, 17, 365)` 向 `(0, 52, 0)`，另从南北两侧贴近屋盖边观察柱下和架空中跨。基座、实际入口台阶和福中三路的衔接尚缺细测。独立体量、公共路径和邻街仍需实走。

源对象、分段生成和正式场景均已核对，浏览器达到可见级。北侧约 `(3.1, 160.55, −475.6)`、52° 视场可见西黄东红双塔、上翘和四处采光井。截图记录初次接入的配色，顶面蓝色和夜间檐灯随后加深。[正午截图](../qa/m2-ground/civic-center-model-day.png) · [午夜截图](../qa/m2-ground/civic-center-model-night.png)

自动测试验证两翼开口、上翘、斜塔、屋盖边界与中跨净空，屋面渲染与切片碰撞采用同一组三角体。浏览器按键实走从南广场 `(3.50, 12.21, 92.11)` 到 `(6.67, 13.38, 39.49)`，进入大屋盖中跨。继续向北并向东偏移后，在 `(15.23, 6.84, −38.91)` 停下。离线用相同人体碰撞范围复核，停点命中中区基座 `relation/10837978`，再往北约 0.05 米会同时碰到东裙房 `way/781536979`。即使沿中轴，地形接触高度与基座顶仍有高差。基座顶部参与结构面接触，北端台阶、接触面切换和中轴全程仍待实走。[南面进入中跨](../qa/m2-ground/civic-center-walk-approach.png) · [北段停点](../qa/m2-ground/civic-center-walk-north.png)

接地分派修复后的同数据自动回放中，沿中轴 `x=0` 在 `z≈27.77` 接到基座顶 Y≈11.66 米，经过 `z≈−73.77` 后切回地形，最终到 `z≈−98.06`。这是控制器回放，北端台阶实景仍待核对，更新版键盘游玩需要另验。
