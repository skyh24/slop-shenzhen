## 4. P0 与已知风险

- 派生路面是公开规则的可复现估计：`min(FABDEM 中值滤波, 原 DSM)`、共享节点中值、道路等级纵坡（6–10%）、平台半径 `半宽+1.5×格距`、过渡带 15–45 m、逐顶点上限 `原 DSM +0.5 m`；不写实测。原始 DSM 与 FABDEM 文件均在 `data/source/sources.json` / `terrain-candidates.json` 记录哈希与许可（FABDEM 为 CC BY-NC-SA，仅非商业）。
- 树木：6.7% 运行时因地形探针无效跳过；`tree_row` 是线派生多点，不是逐株实测；广场面避让只覆盖 pedestrian 线；树种/树高/冠幅为估计（`species-estimate`），只有 25 个点有 OSM 高度/冠幅标签。
- 误识别过滤保守优先：与任何 OSM/Overture 对照轮廓相交的都不丢；保留的 1 个中轴线广场 210 m² / 4 m 高轮廓即因与 Overture 轮廓重叠。
- APEC 花坛、转播车、门前偏移为示意；不使用官方会徽。
- 路灯点位由源路网中心线派生，不是逐杆实测；杆体尚无碰撞。
- 服务器：`python3 tools/sz/serve.py --port 8080` 常驻，打开 <http://127.0.0.1:8080/>（WebGPU 需 localhost/127.0.0.1）。`mvp.html` 只是历史参考。
- `ref/` 只读；`data/raw/`、`docs/qa/` 只留本地。
