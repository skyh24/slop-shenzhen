# 17 普通楼来源、误检过滤与街景核对（2026-11-10）

用户要求：说清楚有数据的楼有多少对齐、其他普通楼是怎么产生的、地图上没有标记的楼不要随机生成，并检查街景、具体楼对应和改进点。

## 1. 结论先说

- **没有任何一批楼是程序随机放置的。** 所有楼都有数据来源：OSM 地图标注、Overture 建筑足迹、3D-GloBFP 卫星足迹。只有"楼高"在 7,333 栋没有任何高度数据时按"类别 + 面积 + 固定种子"估计，属于估计值，已标 `estimate`。
- 当前生产包 **36,980 栋**：OSM 标注 **12,692**（34.3%）、Overture 足迹 **16,565**（44.8%）、GloBFP 足迹 **7,723**（20.9%）。Overture/GloBFP 是遥感/地图衍生数据，不是随机楼，但确实不来自 OSM 地图标注；本轮已加"误检过滤"和 `--footprint-source osm` 纯 OSM 模式。
- **楼高有显式来源的只有 5,180 栋（14.0%）**：OSM `height` 951 + OSM 层数 4,219 + 公开资料修正 4 + 地标 6。其余是 GloBFP 遥感反演 24,443（66.1%）或按类别面积估计 7,333（19.8%）。
- 本轮过滤掉 **2,976 栋**明显误检的遥感补充楼：水面/湿地 68、公园深处 869、孤立小棚 2,039。生产包从 39,956 降到 36,980。

## 3. 误检过滤：不再在空地/水面/公园深处"长楼"

只作用于 Overture/GloBFP 补充楼，**OSM 已标注的楼永远保留**。规则（写入构建报告 `buildingFootprintFilter`）：

1. 和水面/湿地重叠 >20% → 删除；
2. 和绿地重叠 >60%，且 60m 内没有 OSM 楼 → 删除（多为树冠/公园设施误检）；
3. 面积 <60m²，且 50m 内没有 OSM 楼 → 删除（多为围墙、棚子、临时建筑）。

| 命中规则 | 删除数量 |
| --- | ---: |
| 水面/湿地 | 68 |
| 公园深处 | 869 |
| 孤立小棚 | 2,039 |
| **合计** | **2,976** |

示例：深圳湾/大沙河边上 64 个 GloBFP 足迹直接落在水里；莲花山、红树林、世界之窗周边 869 个落在绿地深处；滨海大道/深圳湾公园 2,039 个孤立小方块大多不是楼。构建报告保留每条被删 id、面积和重叠比例，方便回查。

如要**严格只用地图标注的楼**，可以重建：

```sh
.venv/bin/python tools/sz/build.py --footprint-source osm
```

这条命令只保留 12,853 条 OSM 足迹（约 12,692 栋），不加入 Overture/GloBFP；代价是城中村、部分小区会明显变稀。默认仍是 `all`，因为原文档把 OSM 漏掉的楼作为补充目标。

街面观察：

- **华强北**：现实是宽阔步行街 + 花坛/树池 + 底商招牌 + 人流 + 共享单车；我们是一条车行谷地，人行道、铺装、花坛、人群、底商基本没有，招牌只有小块黑色字牌。位置也偏：传送点 `(2700,260)` 附近没有 OSM 道路，说明华强北步行街没有按可走街区建模。
- **深南大道/福田**：现实道路有明确道牙、人行道、行道树、路灯、路牌、底层商铺/雨棚；我们的路面是一整块深色沥青，人行道缺失，楼直接落到地面，没有底商和行人。
- **后海/白石洲**：地面大片空白，树木稀疏；春茧周边的广场、绿化和道路关系没做出来，镜头里像一个白色骨架放在空地上。
- **共同问题**：这是 [11-MVP](11-MVP.md) 里已知的 P0 地面问题（DSM 鼓包、缺人行道/路缘/路灯），不是楼本身随机。

具体楼对照：

- **平安金融中心**：高度对（599.1m），但形体太"针"：真实塔楼有 V 形斜撑、切角、宽基座和顶部收分；我们目前是细长锥体，近看不像。
- **市民中心**：屋顶弧线、红黄柱体和两侧翼楼关系对，但屋顶曲面、柱廊、广场和周边绿化简化很多。
- **春茧**：菱形网格骨架已经在，但外壳太透、没有看台细部和广场景观，近看像线框。
- **大疆天空之城**：真实是双塔 + 高空连桥，我们从这个角度看到的是多栋普通楼的组合，连桥和双塔的可读性不足，需要核对地标模型与周边 OSM 楼的关系。
- **腾讯滨海**：双塔和连桥体量在，细部和连桥位置还可以再对照片校。

## 5. 改进清单（按优先级）

1. **P0 地面/街道剖面**：道牙、人行道、铺装、路缘石、路灯、路牌；这是街景差距最大的来源，也是 12 号文档的 P0。
2. **P0 华强北步行街**：把步行街按真实可走街区补出来（当前 OSM 没在路网里），补花坛、树池、底商雨棚、招牌、人流、共享单车。
3. **P1 普通建筑底商**：一层做连续店面/雨棚/招牌，而不是整栋楼一个立面；城中村一层做小门面。
4. **P1 地标形体**：平安的斜撑和切角；大疆双塔+连桥；春茧外壳实面和广场；市民中心屋顶/柱廊。先改最容易被认出的平安、大疆。
5. **P1 街景生态**：行道树密度、灌木花坛、行人、非机动车、路边停车、公交站；现在树和人都太少。
6. **P2 数据缺口**：信息枢纽大厦主楼、联合广场塔楼、南山科技联合大厦、中洲滨海 T1/T2（见 16 号文档第 5 节），需要重新提取足迹，不能拉高裙楼代替。
7. **P2 普通楼立面**：目前只有 8 类立面、窗户是程序化网格；和照片比，玻璃幕墙反射、阳台细节、屋顶设备还可以继续加强。
8. **P3 高度数据**：7,333 栋估计高度、24,443 栋 GloBFP 反演高度没有逐栋实测；后续可按样区核验，不建议按观感直接改。
