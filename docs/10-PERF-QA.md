# 10 性能与验收

## 性能预算（M1 Pro 级别笔记本，1440p）

| 项 | 预算 |
| --- | --- |
| 首次进入（缓存为空） | 15 秒内可操作 |
| 帧率 | 地面 60 帧，飞行 50 帧以上 |
| 绘制调用 | 每帧 1500 次以内 |
| 三角形 | 每帧 600 万以内 |
| 运行时数据下载 | 压缩后 25 MB 以内 |
| 显存 | 1.5 GB 以内 |

## 手段

- 地面、建筑按 500 米网格分块合批，交给 `scene-culling.js` 做视锥剔除
- 建筑细节只在玩家周围 560 米流式生成
- 树、车、行人、无人机全部实例化
- 远景用低精度网格
- 首屏只编译当前视野用到的着色器，其余后台预热（沿用纽约启动顺序里的 `compile`、`warmup`）

## 数据审计

`tools/sz/build.py` 生成 `data/source/build-report.json`：

- 建筑总数、各高度来源占比
- 道路总长、可驾驶路网最大强连通部分的占比
- 地标是否都对位成功，偏移距离
- 和上一次构建的差异

## 浏览器验收路线

1. 打开页面，等待加载完成，控制台无报错
2. 步行：在市民中心广场出生，走到中轴线北端
3. 开车：按 `2`，沿福华路往西开到车公庙，再沿深南大道开到科技园
4. 飞行：按 `4`，飞到深圳湾上空看后海天际线，再飞到腾讯滨海大厦楼顶降落
5. 夜晚：时间调到 20:00，看灯光秀
6. 地图：按 `M`，搜索“平安”，传送到平安大厦
7. 接单：开出租车接一单并送达

每一步截图保存在 `docs/qa/`。
