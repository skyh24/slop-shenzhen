# 正式验收标准

本文件定义通过条件；当前结果只在 HANDOFF，后续工作只在 TASKS。日常频率按25号，以下完整路线和性能协议用于里程碑/大版本。

## 九条硬性要求

| # | 正式版要求 |
| --- | --- |
| 1 | 地标独立程序化还原，标志特征和周边关系齐全；普通楼保留真实足迹、内院、塔裙/架空分段。可靠同口径高度误差≤3%；估计尺寸不套实测精度结论 |
| 2 | 有来源的山体、海岸、红树林和河道；主要立交匝道实际可通行；深圳湾大桥、沿江高速远景 |
| 3 | 无人机真实站点与航线事实附来源/核实日；示意航迹、高度、模拟行为明确区分 |
| 4 | 深圳地铁network、线路/站/出口及官方色正确；全图单套菜单，首次全关，持久化可用 |
| 5 | 福田站地面部分与公共接驳；西丽按在建状态展示，不画无来源线路 |
| 6 | 纽约原版index结构、元素ID、快捷键与四种移动入口保持对应，中文/地图/触屏可用 |
| 7 | 深圳湾超级总部按建好形态展示，设计高度标design；双塔/连廊/公共空间可辨 |
| 8 | 国际交流中心、会展中心新闻中心、深业上城国礼展及城市元素按来源表达，不使用官方会徽 |
| 9 | 同机位日夜观感、操作连续性与下列性能预算全部达标 |

## 证据口径

L1来源/数据 → L2生成 → L3正式场景 → L4浏览器可见 → L5显示/接触一致且实际操作。逐项写范围、等级、通过/部分/失败/未测与证据；一个路口成功不外推全城。

- 源身份、采集/版本/核实日期、许可、哈希、坐标/垂直基准、估计方法可追溯。包变化保留对象级差异、影响块和范围外变化。
- 全量自动检查通过、0跳过，真实Three版本0.187.0；正常冷启动控制台无应用错误。工具/扩展错误须有上下文归因，原始日志保留。
- 起点可正常传送，被验区段必须连续实际输入完成。手动驾驶、自动驾驶和环境车流分开记录，不能改内部坐标或直接调用完成函数代替操作。

## 几何与行为

| 检查 | 通过依据 |
| --- | --- |
| QA-G01 工程面 | 独立控制点、平面配准残差、垂直基准；至少1条纵剖+2处横剖，误差在来源不确定度内；缺基准不判真实标高通过 |
| QA-G02 接缝 | 路面→路缘→人行道→前场→入口往返，合法道路跨缝；无浮起、埋门、尖脊/闪烁、隐藏旧地面。共享边界顶点计算误差≤1mm |
| QA-G03 接触 | 记录surfaceId、脚/轮与完整活动支撑面的高度差；静止稳定后目标≤2cm，运动最大/P95另列；无异常升降或穿透 |
| QA-B01 建筑 | 源足迹和图照对位，地面/中远景、日夜；核屋顶、塔裙、门洞、连桥、内院、邻楼，射线加实际通行 |
| QA-R01 交通 | 合法双向、起终点/前往起点、信号等待、手动接管/到达；可达/不可达各例，环境车连续≥5min，记录堵塞/恢复/数量，无撞穿和可见闪消 |
| QA-R02 立交 | 地面→上桥→桥面→下桥→地面与桥下分别走通；显示/碰撞/导航同面，净空与结构高程有来源，不逆行、不串层 |
| QA-P01 公园 | 200–400m有来源步道与入口，抽查15–30个树/设施；通路不被植被/街具堵塞，球场只验已核对象 |
| QA-M01 轨道交通 | 新会话全关、逐线/全选/关闭/刷新、搜索缩放；服务关系不冒充物理线路，出口身份和地图点/实物对应 |
| QA-A01 低空 | 站点/配对/日期分别有据，未知轨迹标示意；旋翼/货箱/起降/停运可见，未知净空不穿楼 |
| QA-V01 载具人物 | 模式切换、同一乘员坐姿、安全上下车/起降；静止及动态人车、跨帧高速、跨层与受阻失败恢复 |
| QA-UI01 UI | 原版ID/键位、四时段、菜单/地图/声音/隐藏/相机；触屏竖屏和手柄另测，新增交互按已确认需求 |

1mm是几何边界计算一致性，2cm是静止接触门槛，都不是测绘精度；失败不得放宽阈值消除。

## 性能预算

目标M1 Pro级设备，渲染输出2560×1440。记录硬件/系统/浏览器、CSS视口、DPR、pixelRatio、缩放、阴影/后处理、相机、时段、交通种子/数量。

| 项 | 预算与采样 |
| --- | --- |
| 冷启动 | 空HTTP缓存到首帧且输入可用≤15秒；分开记下载/解压/解析/解码/建模/GPU编译/预热 |
| 帧率 | 地面≥60FPS、飞行≥50FPS；每稳定段≥60秒，报帧间隔P50/P95 |
| 绘制/三角 | 每帧≤1500次/600万；报P50/P95/最大 |
| 数据传输 | 压缩运行数据≤25MB；另列引擎/脚本/字体及完整首访流量 |
| 显存 | ≤1.5GB；可测/不可测分开，资源计数不等于总VRAM，无法可靠测量就标未测 |
| 稳定性 | ≥20分钟跨块驾驶/飞行/传送往返；相同地点比较资源量，检查泄漏、设备丢失、输入失效与死锁 |

冷热各≥5次，列逐次、P50/P95/最差。使用可见聚焦窗口；后台30Hz样本不能证明性能。前后同配置，启动/切镜窗口与稳定段分开；不清空用户整个浏览器资料。`tools/qa/perf-sample.mjs` 使用前核实际环境参数和采样长度。

## 加载与发布

- 同载荷比较JSON/SZC1，检查精度、源身份、接缝、接触、坏包/慢网络/重试；格式更换不代表真实性改善。
- 流式数据须保留概览/搜索及跨块路网和surfaceId；预取随速度变化，缓存有界，释放几何/贴图，不卸载正在使用的接触面和交通状态。
- 发布只收运行依赖，原生源码保留；代码/数据/报告同版本，验证首访、热缓存、更新/回退、gzip重复压缩与资源路径。新增构建工具须另获明确决定。
- 证据放本地 `docs/qa/<批次>/`：基线/包哈希、来源、配置、截图、真实输入轨迹、接触/性能原始样本、控制台、测试/审查与缺口。结束恢复普通游玩状态；全通过才按25号发布里程碑。
