# 10 性能与验收

更新：2026-11-09。本文件定义“通过”的证据，不表示当前已通过。当前结果见[HANDOFF](HANDOFF.md)，下一批顺序见[NEXT-AGENT-PLAN](NEXT-AGENT-PLAN.md)。

## 1. 五级状态与通用门槛

L1来源/数据 → L2生成 → L3正式场景接入 → L4浏览器可见 → L5实际操作与显示/接触一致。每条任务注明范围、级别、结果（通过/部分/失败/未测）、证据路径和剩余问题。一个路口成功不能外推全城；截图与单测不能替代实际操作；短途通行不能证明真实标高。

每批必查：

- 源身份、下载/内容日期、许可、哈希、坐标系和垂直基准；实测/源标签/设计/预测/插值/外观估计逐字段区分。未知写未知。
- 生成只经build.py；报告包含对象级变化、数量、未知/冲突/隔离项。无通用自动差异报告时另做包比较，不能声称build-report已有全部差异。
- 保存前版包哈希和代码/工作树基线；影响范围外对象属性、足迹和表面须完全不变，除非列出并审核预期差异。不要在保存基线前重建覆盖。
- 自动测试全部通过且报告skip；依赖真实Three的测试须用0.187.0。浏览器冷启动无未解释的应用错误；扩展/工具错误有脚本上下文证据后才可剔除，原始日志保留。
- 结尾恢复普通URL、界面、追尾/常规游玩状态；移除本轮固定调试机位状态和测试参数，保留正常相机菜单功能。

## 2. 几何与操作验收矩阵

| 编号 | 对象与步骤 | 通过条件/必须留下的证据 |
| --- | --- | --- |
| QA-G01 | 道路/前场控制点与工程面 | 平面配准含独立校核点、残差；确认垂直基准/转换和现状或设计时间。至少纵剖面+两处横剖面，显示控制点、旧DSM和新面。误差不超过来源声明的不确定度；来源不明时不能判真实高度通过 |
| QA-G02 | 路面—路缘—人行道—前场—入口 | 同机位近地/斜视/俯视前后图；实际走过所有接缝并往返，车在合法道路跨缝。无浮起、埋门、尖脊、闪烁、隐藏旧地面和假斜坡。接缝共享同一世界坐标顶点；浮点计算核对默认≤1mm，不把分米编码误差或测绘误差混作同一阈值 |
| QA-G03 | 人脚/车轮接触 | 与完整活动支撑面比较，包括铺装抬高、平台、桥面；记录surfaceId、位置、支撑高、脚/轮高及残差。静止稳定后的接触目标≤2cm；运动最大值和P95单列，悬架/步行缓动有代码依据。不能只比原DSM中心；不能靠调阈值吞掉穿透 |
| QA-B01 | 地标/普通楼与裙房 | 参考图与源足迹对位，日夜、地面/中景/远景对照。核塔裙比例、屋顶、收分、凹槽、连桥/柱廊、真实内院；无重复实体/误删邻楼。已知可靠高度按11号要求，估计尺寸不宣称3%实测精度。碰撞射线和实际输入检查墙/柱/桥底/桥面 |
| QA-R01 | 深南/北环驾驶与动态交通 | 两个合法方向分别跑；地图选起终点、前往起点、启动、信号停车/放行、手动接管、到达停止。保留环境车；连续至少5min记录数量、堵塞位置/原因/时长、回收与恢复，无撞穿/可见车闪消。可达和不可达各一例，不串联缺失桥高 |
| QA-R02 | 完整立交与上下层 | 地面→上桥→桥面→下桥→地面及桥下道路分别走通；路宽/纵横断面/净空有来源，显示/碰撞/导航同面；桥上桥下不误碰/串层、轮胎不脱离、无缝隙掉落。单向匝道不逆行验收 |
| QA-P01 | 公园/邻楼环境 | 沿200–400m有来源主路径及真实入口行走，核15–30个树或设施；树干不占路/入口，草坪不穿楼、屋顶绿地不误删。球场仅对已核真实对象验边界、标线、器械、围网、灯杆/通道；未取得来源标未测 |
| QA-M01 | 地铁/高铁地图 | 新会话默认线路关闭，逐条/全部开关、持久化、搜索与缩放实操；核深圳network、不混外城同号线，车公庙换乘/出口逐源对照。42服务关系不说42线，歧义出口不硬关联。地下透视深度/列车非实时模拟须标明 |
| QA-A01 | 配送、表演与低空 | 逐站位置/时间/来源；真实运营轨迹与端点事实分开。只有端点不得造“真实”路径；展示推算路径必须明确示意。无人机模型、旋翼、货箱、站点起降、障碍/停运状态实操，未知安全净空不穿楼 |
| QA-V01 | 车辆/人物/四旋翼 | 模式切换、乘员坐姿、车身/旋翼/乘员位置一致，安全上/下车与起降；静止车、人、车之间与跨层动态碰撞验证，不能用二维距离误撞桥下。按07/08/14的具体状态规则测失败恢复 |
| QA-UI01 | NY对应与新交互 | 逐个元素ID/菜单/快捷键和四模式对照，四时段、地图、声音/隐藏、相机；触屏竖屏和手柄另测。14号新交互显式覆盖的部分按新规则，点击浮签与传送分开；UI文字集中管理 |

QA-G02的1mm是共用边界计算一致性要求，QA-G03的2cm是静止接触工程门槛，均非地理测量精度。若现有系统达不到，记录失败和原因，不擅自放宽。连续运动出现与源数据无关的异常升降或碰撞穿透也算失败，即使平均残差小。

## 3. 性能预算与测量协议

目标设备为M1 Pro级笔记本，**渲染输出2560×1440**。同时记录CSS视口、DPR、渲染pixelRatio、浏览器缩放、浏览器/OS/硬件、后处理/阴影配置、时间、相机、交通种子与数量。不同截图分辨率或缩放不是同配置基准。

| 项 | 预算与口径 |
| --- | --- |
| 冷启动 | 空HTTP资源缓存，导航开始至场景首帧完成且真实输入生效≤15s；每次列下载/解压/解析/解码/构建/编译/预热/可操作耗时 |
| 帧率 | 固定地面路线≥60FPS，飞行≥50FPS；每段稳定采样≥60s，原始帧间隔P50/P95同时报告，短HUD值不算验收 |
| 绘制调用/三角形 | 每帧≤1500次/600万；报告P50/P95/最大值，而非仅均值 |
| 运行数据下载 | 压缩数据≤25MB；另列引擎/脚本/字体等完整首访传输，不用gzip包大小冒充全站大小 |
| 显存 | ≤1.5GB；API可测部分/不可测部分分开，renderer资源计数不是进程全部VRAM。无可靠总量时写未测，不判此项通过 |
| 长时稳定性 | 至少20min跨块驾驶/飞行/传送往返，比较相同地点/视野资源计数，检查持续增长、设备丢失、输入失效及车流死锁 |

冷/热缓存各至少5次，同一环境列每次、P50/P95及最差。不清空用户整个浏览器资料/其他网站数据；使用任务专属会话或已授权的单站缓存控制。冷/热与持久化状态口径分开，停用无关压力任务。GPU时间戳和60FPS明显矛盾时核测量来源，不挑较好一项宣称通过。

缺少P50/最大值等指标时先补可复现的采样工具。前后性能必须同设备、相机/时间/交通配置；变化只归因可控制的差异。启动和切相机窗口不混入稳定段。现有约10秒记录只是局部诊断。

## 5. 单项证据模板与交付

每个样区在`docs/qa/<批次>/`写README和机器可读记录，至少包含：

- 任务ID/范围/状态/L1–L5，源ID、版本/哈希、代码提交和未提交摘要。
- 前后数据包哈希、对象属性/几何差异、受影响分块、范围外差异；控制点/拟合/不确定性（如适用）。
- 浏览器环境、相机位置/目标/FOV、时间、viewport/DPR/缩放、交通参数；同机位前后截图与原始参考出处。
- 输入方式、起止位置、轨迹采样时间、途中阻挡/信号/上下层、完整接触面身份、残差与连续性；有采样间断明确标出。
- 控制台/网络/设备错误原始记录与归因，测试命令/结果/skip，性能原始样本及统计。
- 未通过项、数据缺口、下一步和恢复普通游玩状态记录。

里程碑仅在相关源数据、生成、画面、实操、性能和文档全通过后勾选，并按仓库规则提交/推送及标记baseline。仅局部修复或本文档整理不触发里程碑发布。
