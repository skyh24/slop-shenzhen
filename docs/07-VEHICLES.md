# 载具、驾驶与车流

## 已有功能

正式入口支持步行、汽车、单车和玩家飞行器四模式。模式切换绑定同一人物，保留横向位置与朝向，只显示当前使用的玩家载具。深圳载具包括蓝白高顶出租车、环境车型/公交、共享单车、四旋翼和货运无人机，均为无品牌程序模型。

已有路网自动驾驶、信号等待、手动接管和环境车流。出租车接单、乘客上落点与结算闭环尚未实现。货运航线是独立系统，见 [无人机](08-AIR.md)。

自动驾驶、定速循道与环境车在地面和立交读取同一车道断面。结构接缝不再回退到整幅道路中线；双车道分别使用各自中心，估计车道也与可见标线保持一致。

## 玩家移动

| 快捷键 | 模式 | 前进 / 后退上限（游戏参数） |
| --- | --- | --- |
| 1 | 步行 | 30 / 20 km/h |
| 2 | 骑行 | 60 / 40 km/h，Shift 前进可达 100 km/h，每秒加速 20 km/h |
| 3 | 汽车 | 80 / 80 km/h，Shift 前进可达 160 km/h，每秒加速 40 km/h |
| 4 | 飞行 | 600 / 400 km/h，每秒加速 200 km/h，最大升降速度 30 m/s |

手动车辆和飞行器松开前后输入后，水平速度在 5 秒内降到零。空格（汽车、单车）或 X（飞行）刹车，或按与行进方向相反的键，均在 1 秒内先刹停；持续按反向键才反向起步。速度条以含 Shift 的前进极速为满格。手动开车接近同层前方车辆或行人时闪前灯，不提前制动。手驾汽车可以穿过行人、路灯和树木，不减速、不回弹；其他车辆和建筑仍有碰撞。自动驾驶和环境车仍按原规则礼让行人。

四种模式均支持 F 或点击速度栏定速，显示离地高度。汽车沿可用车道循道，按曲率和抓地预算过弯；人工转向可暂时接管方向，刹车解除定速。地图自动驾驶还需合法路线、同层起点与净空。自动驾驶与定速时，J/K 请求左/右换道，L 开关换道辅助。

空中巡游沿深南、北环或滨海线路接管玩家飞行器，提供 300/600 km/h 两档、暂停、重启与退出。换速按里程保持位置连续，退出后在当前位置悬停。飞行切换到地面模式时，优先选机身下方最高、完整承托且无障碍的车行桥面；没有合格桥面时再用常规落点规则，失败时保留飞行模式。

## URL 自动驾驶样段

本机地址加 `qa=1&driveFrom=起点&driveTo=终点`，加载完成后自动规划、切换汽车并出发。起终点可用现有地标 ID 或米制 `x,z` 坐标，也能混用；二维点优先吸附到附近地面车道，起点朝向取路线方向，终点是临路停车点。路线复用正式信号、承托、碰撞与到站停车，不绕过通行检查。

| 地标 | URL 中的 ID |
| --- | --- |
| 深圳市民中心 | `civic-center` |
| 车公庙片区 | `chegongmiao` |
| 深圳特区报业大厦 | `press-tower` |
| 华强北 | `huaqiangbei` |
| 腾讯大厦 | `tencent-towers` |

地标组合例子：`/?qa=1&driveFrom=civic-center&driveTo=press-tower`。它用于设置端点，不代表该组合已验收。车公庙深南大道辅路回归入口：`/?qa=1&driveFrom=-3245,817&driveTo=-3135,798`。旧工作树在桌面 Ego 到站停车（111.63 米）；11 月 19 日全量重建后的同坐标返回无合法路线，当前不能作为自动驾驶成功示例。

地面—立交—地面接续样段：`/?qa=1&driveFrom=-3311.9624,730.481&driveTo=-3179.0028,975.6674`。共用断面后，此段在桌面 Ego 浏览器自动通过 445.91 米并到站停车，包含单车道引道、三车道桥面和双车道下桥接地（局部 L5）。日常选其中一条样段即可。

`__szQA().urlDrive` 与 DOM 中 `#qa-drive-result` 的 JSON 记录端点、实际路线、当前状态和错误；后者另含里程和车位。到站状态为 `arrived`，人工接管、受阻和出发失败分别保留实际状态。地标未知、坐标格式错误或无合法路线会返回 `failed` 与错误原因。该入口只在本机回环地址的 QA 模式启用。

## 车道级环境车流

车流沿有向路网的车道中心行驶，候选出生车道按附近车流分布选取。前车持续妨碍通行时，只并入同向相邻且更畅通的车道；净距按同层车辆前后位置和接近速度判断，靠近路口、匝道分岔或等信号时不抢道。并线时逐步检查轮胎承托和车身碰撞，完成后留在新车道，保留原定路口走向。没有安全空隙就跟车等待。这套规则不接管手动驾驶。在路线末端前续接，停滞车辆只在远离玩家且不可见时回收。

环境车对迎面风险减速刹停，受尾击后在前车和路段限速允许范围内加速。QA 模式的 `__szQA().traffic` 提供长停车辆、队列长度、换道与路线续接指标。测试须区分正常等灯、玩家占道和失去路线。[人车优化项](TASKS.md#t8-人车)
